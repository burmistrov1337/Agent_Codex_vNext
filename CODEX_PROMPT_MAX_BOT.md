# ПРОМТ ДЛЯ CODEX — Реализация бота в мессенджере Max

## КОНТЕКСТ ПРОЕКТА

Ты — AI-ассистент для разработки. Тебе нужно создать бота для мессенджера Max, который объединяет три платформы:

1. **Интернет-магазин ADK Cosmetics** — adkcosmetics.ru (косметические ингредиенты)
2. **Платформа SaveYourHair** — saveyourhair.ru (уход за волосами)
3. **Telegram-канал** — @ustore_active (инструкции, рецепты, консультации)

## API КЛЮЧИ И ДОСТУПЫ

```
MAX_BOT_API_KEY = {ВСТАВИТЬ API КЛЮЧ БОТА MAX}
MAX_BOT_ID = {ВСТАВИТЬ ID БОТА}
TELEGRAM_BOT_TOKEN = {ВСТАВИТЬ TELEGRAM BOT TOKEN}
```

## ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ

### Стек
- Python 3.11+
- aiohttp для асинхронных HTTP запросов к API Max
- SQLite для MVP (с возможностью миграции на PostgreSQL)
- aiofiles для работы с файлами

### 1.4 Поиск инструкции к продукту

**Реализуй два способа поиска:**

**Способ A — Поиск по названию/INCI:**
- Пользователь вводит текст
- Бот ищет в базе знаний (JSON файл для MVP)
- Выдает результат:
  ```
  "Ваш выбор: [Название товара]
  Ознакомиться с инструкцией по применению вы можете в этом посте:"
  [Гиперссылка на пост в Telegram канале]
  ```

**Способ B — Поиск по категориям:**
- Inline кнопки с категориями:
  - Экстракты
  - Консерванты
  - Эфирные масла
  - Базовые масла
  - Активные компоненты
  - Эмульгаторы
- При выборе категории — список товаров
- При выборе товара — ссылка на инструкцию

### 1.5 База данных (SQLite для MVP)

Создай таблицы:
```sql
CREATE TABLE users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    max_user_id TEXT UNIQUE NOT NULL,
    username TEXT,
    first_name TEXT,
    last_name TEXT,
    consent_given BOOLEAN DEFAULT FALSE,
    telegram_subscribed BOOLEAN DEFAULT FALSE,
    preference TEXT,  -- 'ingredients', 'hair', 'both'
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    last_active TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE user_interactions (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER REFERENCES users(id),
    action_type TEXT,  -- 'search', 'category_view', 'product_view'
    action_data TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE products (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    inci TEXT,
    category TEXT,
    description TEXT,
    instruction_link TEXT,  -- ссылка на пост в Telegram
    shop_link TEXT,         -- ссылка на товар в магазине
    price REAL,
    image_url TEXT
);
```
