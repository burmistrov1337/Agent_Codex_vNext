# АРХИТЕКТУРА БОТА MAX — ADK Cosmetics / SaveYourHair

## 1. ОБЗОР ПРОЕКТА

### 1.1 Цель
Создать многофункционального бота в мессенджере Max, который объединяет:
- Интернет-магазин ADK Cosmetics (adkcosmetics.ru)
- Платформу SaveYourHair (saveyourhair.ru)
- Telegram-канал @ustore_active
- Базу знаний по ингредиентам и рецептам
- Систему консультаций с технологом-тритментологом

### 1.2 Целевая аудитория
- Покупатели косметических ингредиентов
- Домашние косметологи
- Профессиональные трихологи и косметологи
- Бьюти-блогеры и энтузиасты

### 2.2 Онбординг (первичный сценарий)

**Шаг 1: Приветствие**
- Текст: «Здравствуйте! Добро пожаловать в ADK cosmetics — ваш проводник в мир профессиональной косметологии и здоровых волос!»
- Кнопка: «Начать»

**Шаг 2: Юридическое согласие**
- Текст с ссылкой на политику конфиденциальности
- Кнопки: «Принимаю» / «Ознакомиться с документами»
- Без принятия — доступ ограничен

**Шаг 3: Подписка на канал**
- Текст о преимуществах канала
- Кнопка: «Подписаться на @ustore_active»
- Кнопка: «Я подписался» (с проверкой)

**Шаг 4: Персонализация**
- Вопрос: «Что вас интересует больше всего?»
- Варианты: «Косметические ингредиенты», «Уход за волосами», «И то и другое»
- На основе ответа формируется главное меню

### 2.3 Основные сценарии

#### Сценарий А: Поиск инструкции к продукту
1. Пользователь выбирает «База знаний»
2. Вводит название или INCI
3. Бот ищет в базе и выдает:
   - Описание компонента
   - Ссылку на пост в канале с инструкцией
   - Рекомендуемые рецепты
   - Сопутствующие товары из магазина

#### Сценарий Б: Покупка в магазине
1. Пользователь выбирает «Магазин ADK»
2. Просматривает каталог по категориям
3. Добавляет товары в корзину
4. Оформляет заказ через бота
5. Получает трек-номер и уведомления о статусе

#### Сценарий В: Консультация по волосам
1. Пользователь выбирает «SaveYourHair»
2. Проходит мини-диагностику (вопросы о состоянии волос)
3. Получает рекомендации по уходу
4. Может записаться к специалисту
5. Получает подборку товаров для его случая

#### Сценарий Г: Связь с экспертом
1. Пользователь выбирает «Консультация эксперта»
2. Описывает проблему
3. Может прикрепить фото
4. Получает ответ от технолога
5. При необходимости — запись на онлайн-консультацию

## 4. ТЕХНИЧЕСКАЯ АРХИТЕКТУРА

### 4.1 Стек технологий
- **Backend:** Python 3.11+, FastAPI или aiohttp
- **База данных:** PostgreSQL (основная), Redis (кэш/сессии)
- **Очереди:** RabbitMQ или Celery + Redis
- **API:** REST + WebSocket для real-time уведомлений
- **Хостинг:** Docker + Docker Compose

### 4.2 Структура проекта
```
max_bot/
├── bot/
│   ├── handlers/           # Обработчики команд
│   ├── keyboards/          # Клавиатуры и меню
│   ├── middlewares/        # Промежуточные обработчики
│   └── states/             # FSM состояния
├── services/
│   ├── shop_api.py         # Интеграция с adkcosmetics.ru
│   ├── hair_api.py         # Интеграция с saveyourhair.ru
│   ├── telegram_api.py     # Интеграция с Telegram
│   ├── knowledge_base.py   # База знаний
│   └── notification.py     # Уведомления
├── models/                 # SQLAlchemy модели
├── utils/                  # Утилиты
├── config/                 # Конфигурация
├── migrations/             # Миграции БД
└── main.py                 # Точка входа
```

### 4.3 База данных (основные таблицы)
- `users` — профили пользователей
- `user_preferences` — предпочтения и интересы
- `products` — каталог товаров
- `categories` — категории товаров
- `orders` — заказы
- `order_items` — позиции заказа
- `knowledge_articles` — статьи базы знаний
- `recipes` — рецепты
- `consultations` — консультации
- `subscriptions` — подписки

## 6. СЦЕНАРИИ УДЕРЖАНИЯ

### 6.1 Push-уведомления
- Новые поступления товаров
- Персональные рекомендации
- Напоминания о брошенной корзине
- Акции и скидки

### 6.2 Контент-воронка
1. Пользователь пришел за инструкцией
2. Получил рецепт → заинтересовался ингредиентами
3. Перешел в магазин → сделал покупку
4. Подписался на канал → стал лояльным клиентом
5. Оставил отзыв → привлек других

### 6.3 Программа лояльности
- 1 балл за каждые 100₽ покупки
- 50 баллов за подписку на канал
- 100 баллов за отзыв
- 200 баллов за реферала
- Обмен баллов на скидки
